# 用 MLP 预测月租

一个把「数据来源 → 特征工程 → MLP 训练 → 导出权重 → 浏览器推理」全流程
打包进**单文件静态 HTML** 的演示项目。

👉 **在线页面：https://eaj35.github.io/rent-mlp/**

## 页面里有什么

- 三类公开网络资料（真实链家房源、35 城租金统计、特征价格实证研究）及其引用
- MLP 原理：网络结构、前向/反向传播公式、ReLU / MSE / Adam
- 训练曲线、验证集指标、单因素敏感性分析
- **可交互的预测器**：拖动滑块，浏览器里实时跑神经网络前向传播，并可视化隐藏层激活
- 完整 Python 训练源码与 JS 推理源码（页面内可直接展开复制）

`index.html` 是自包含的：模型权重、训练曲线、全部代码都已内嵌，
无外部 CDN、无后端、无构建步骤，下载后双击即可离线打开。

## 复现

```bash
pip install numpy
# 下载真实房源数据到 data/lianjia_shanghai.csv
# https://github.com/XiyueWang/shanghai_rental_analysis_lianjia/blob/master/data/lianjia_shanghai.csv
python train_mlp.py     # 训练并导出 model.json
python build_html.py    # 生成单文件 index.html
```

## 数据来源与诚实声明

| 来源 | 说明 |
|---|---|
| 上海链家租房数据集（GitHub 开源，2020-10 抓取） | 10,998 条真实挂牌记录，清洗后 10,253 条 |
| 《财经》35 城住宅租金、中指研究院 50 城报告 | 2025 年各城市租金水平（元/㎡/月） |
| 武汉 / 杭州 / 长沙 / 广州 特征价格模型研究 | 用于校验模型学到的方向 |

**注意**：真实房源只有上海一个城市，不含「城市物价水平」的变化。
因此用公开的城市租金指数对真实房源价格做整体缩放来扩展样本。
最终训练集是**「真实房源结构 + 公开统计标定的扩展样本」**，不是真实多城市成交数据，
**不可用于商业定价或投资判断**。页面里也明确标注了这一点。

## 模型

| 项 | 值 |
|---|---|
| 结构 | 5-24-16-1 |
| 激活 / 损失 / 优化器 | ReLU / MSE / Adam |
| 输入 | 距市中心(km)、装修程度(0-3)、所在楼层、城市物价水平(元/㎡/月)、面积(㎡) |
| 输出 | 月租(元/月) |
| 验证集 R² | 0.8828 |
| MAE | 697 元/月 |

## 局限性

数据有 2020→2026 的时差；装修与楼层是标签折算的代理变量；
城市维度是统计标定扩展；未做正则化调参与交叉验证。详见页面第 8 节。
